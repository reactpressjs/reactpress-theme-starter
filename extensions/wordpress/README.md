| Package | Type | Status |
| --- | --- | --- |
| [ReactPress for WordPress](https://github.com/reactpressjs/reactpress-for-wordpress) | Block theme (FSE) | Moved to standalone repo — WordPress.org review ticket [#298039](https://themes.trac.wordpress.org/ticket/298039) |

## Standalone repository

The official **ReactPress for WordPress** theme (`reactpress-blog`) now lives in:

**https://github.com/reactpressjs/reactpress-for-wordpress**

Clone it, then package with:

```bash
bash pack.sh
```

Upload `dist/reactpress-blog.zip` at https://wordpress.org/themes/upload/
