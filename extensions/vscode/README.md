## Standalone repository

The official **ReactPress for VS Code** extension now lives in:

**https://github.com/reactpressjs/reactpress-for-vscode**

Clone it, then develop or package with:

```bash
git clone https://github.com/reactpressjs/reactpress-for-vscode.git
cd reactpress-for-vscode
pnpm install
pnpm build
pnpm package:vsix
```

Marketplace publish notes: see [PRODUCTION.md](https://github.com/reactpressjs/reactpress-for-vscode/blob/main/PRODUCTION.md) in that repository.
