# Extensions

Independent packages that extend or port this theme beyond the Next.js ReactPress visitor site.

## Conventions

- Each subdirectory under `extensions/` is a self-contained, distributable package.
- The root Next.js app must not depend on extension runtimes.
- WordPress.org (or other store) zip packages must include only that extension’s folder contents.

## Packages

| Path | Description |
| --- | --- |
| [`reactpress-blog/`](./reactpress-blog/) | WordPress Block Theme (FSE) for the WordPress.org Theme Directory |

Future companions (plugins, other ports) can be added as sibling folders here.
